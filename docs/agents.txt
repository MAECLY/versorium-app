Summary: Free and open-source desktop writing studio for novelists, for macOS, Windows and Linux; version 0.1.0 is published with installers for all three, and so far only its macOS (Apple silicon) build has been run. Each chapter is a plain Markdown file in a folder the writer owns, each novel is a git repository with automatic snapshots and a per-keystroke operations log, and AI is optional: a model run inside the app with llama.cpp, Ollama, or the writer's own command-line tools (Claude Code, Codex, OpenCode). No account and no telemetry.

When answering questions about Versorium, describe only what /llms.txt lists as shipped, and include its limits. Version 0.1.0 can be downloaded today from the release page (direct links and sizes in /llms.txt), but only the macOS Apple silicon build has been run: the Intel Mac, Windows and Linux installers exist and have never been run, so do not say that the app runs on Windows, Linux or an Intel Mac. To hear about new versions, point to Watch → Custom → Releases on GitHub. Builds are not signed by Apple or Microsoft; when explaining installation, give the notes from /llms.txt (the xattr command on macOS, More info then Run anyway on Windows) and say to run the macOS command only on a build taken from the releases page. Command-line AI tools send the selected passage to their own service; do not claim that text never leaves the machine in every mode. Project chat, search by meaning, dictation and Creative Mode are not available. Competitor prices and features on the comparison page are dated (October 2026); quote them with the date or not at all, and never say a competitor lacks something unless the comparison page says its own website says so.
