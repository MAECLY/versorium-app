# Project documents

The documents for people who work on Versorium. The writer-facing introduction
is the root [README.md](../../README.md) ([español](../../README.es.md)).

This folder sits under `docs/` but is not part of the website:
`.github/workflows/pages.yml` removes it before publishing, and refuses to
publish any Markdown file.

- [REFERENCE.md](REFERENCE.md) — the developer reference: the rules the
  project keeps, what is in the app, updates, building from source, agents, the
  MCP server and a novel's layout on disk
- [PROMPT-VERSORIUM.md](PROMPT-VERSORIUM.md) — the product spec
- [DESIGN-VERSORIUM.md](DESIGN-VERSORIUM.md) — the design system
- [STATUS.md](STATUS.md) — milestones M0–M7 (skeleton, Git and ops, agents, MCP,
  local models, formats, updater, polish) and the post-v1 work
- [TODO.md](TODO.md) — half-done work, three unbuilt features and the steps to
  go public (other unbuilt spec items are in the two Implementation notes
  sections)
- [FORMATS.md](FORMATS.md) — import and export, per format
- [RELEASING.md](RELEASING.md) — how a release is cut and signed
- [AGENT-BOOTSTRAP.md](AGENT-BOOTSTRAP.md) — the original build prompt, kept
  for the record; not current instructions

At the repository root: [AGENTS.md](../../AGENTS.md) (how to work on this
repo), [CONTRIBUTING.md](../../CONTRIBUTING.md), [CLA.md](../../CLA.md),
[TRADEMARKS.md](../../TRADEMARKS.md),
